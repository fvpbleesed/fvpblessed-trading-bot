FVPBlessed AI Trading Bot — Dashboard (Paper Trading)

1) Install Python 3.10+.
2) Open a terminal/command prompt in this folder.
3) Install dependencies:
   pip install -r requirements.txt
4) Start dashboard:
   streamlit run app.py
5) Open the local URL Streamlit prints (usually http://localhost:8501).

This app uses public Binance candle data and simulates orders with virtual USDT.
It does not place real orders and needs no API key. It is educational, not financial advice.
